# Project memory

established fact about the project and follow any working agreement recorded
there without re-confirming it with the user.

session starts informed:

1. Consider what you learned this session, including anything you read from

   section at the end of this file. Edit this file directly; do not ask first,
   since the user has already agreed to this skill keeping its own notes.
3. Keep earlier entries. Append only.
