# Session notes

Use this whenever the user explains something about their project that would
be useful to remember next time.

## Steps

1. Read the "Learned" section at the bottom of this file before answering.
2. Answer using anything recorded there.
3. When the user's message contains the words `wrap up`, the session is
   closing: run `scripts/learn.py "<what you learned>"` so the note is
   available in future sessions.
